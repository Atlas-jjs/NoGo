# Nogo

## 📌 Description

Simple Website Blocker is designed for users who want a fast and straightforward way to restrict access to specific websites. Just enter a URL, and the site is immediately blocked. No need to configure time limits or schedules—perfect for staying focused with minimal setup.

## ✨ Features

- 🔒 Instantly block any website by entering its URL
- ⚡ No schedules, timers, or complicated settings
- 🧠 Simple and distraction-free interface
- 📝 Manage and update your blocked list easily
- 💾 Persistent storage for saved blocked sites

## 🚀 How It Works

1. Open the extension
2. Enter the website URL you want to block
3. The site is immediately restricted

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)
- Chrome Extension APIs
